# 队友原型参考

此目录保存用户于 2026-08-28 提供的队友前端原型，供“拾光”微信小程序重设计时复用已有页面结构、状态和跳转思考。

## 文件

- `人生之书页面布局.html`：九个手机屏幕状态，包括有内容／空首页、写入面板、AI 对话、叙事生成、详情页和长按菜单。
- `人生之书跳转逻辑.html`：书封面整体与三个数据区域的四条跳转关系。
- `记忆之家页面.html`：十二个手机屏幕状态，包括未创建／无内容、家庭时间线、成员筛选、本人／他人详情、创建家庭空间和邀请双方流程。

## 使用规则

- 三个 HTML 文件按收到时的内容原样保存，不直接修改。
- 它们是静态设计原型，不是原生微信小程序运行代码；实现时需要转译为 WXML、WXSS 和小程序页面交互。
- 优先复用信息架构、页面状态和跳转关系，再按最新需求适配老人角色、事实确认、隐私边界和视觉语言。
- 原型中的深棕配色、小字号、双模式入口和“直接分享”行为不是最终要求，以 `docs/brainstorms/2026-08-28-shared-elder-life-book-redesign-requirements.md` 为准。
