# 90 秒演示视频脚本

## 0–14 秒：问题

画面：极简首页。当前用户的水彩故事封面是最大主体，下方用等宽的书页与屋檐图案分别进入“人生之书”和“记忆之家”，再往下是“开始聊聊”和最近故事。

旁白：

> 一个人的一生不是一本已经排好目录的书。它有很多故事，也有一些暂时说不清、却不该丢掉的片段。

## 14–36 秒：先讲，不分类

画面：点击“继续聊”，AI 先引用上次讲到的内容，再连续追问两个细节。

旁白：

> 在拾光里，不用先判断这是“我的故事”还是“家庭故事”。你只管说，AI 先听，再从人物、时间、地点和感受里陪你慢慢想起来。

## 36–58 秒：故事与片段

画面：点击“整理成片段”。先选“未整理片段”，再演示输入新故事名“我和外公的雨天”。

旁白：

> 聊完以后，可以把它放进一个具体故事，也可以先留在未整理片段里。没有想好名字，不会妨碍这段记忆被好好保存。

## 58–78 秒：人物和权限分开

画面：在“这段和谁有关”选择外公和妈妈；在“谁可以看”只选择妈妈和一位朋友，然后保存。

旁白：

> “和谁有关”只是整理线索，“谁可以看”才是真正的阅读权限。每一段故事都能单独选择家人或朋友，也可以永远只留给自己。

## 78–90 秒：两个阅读视图

画面：退出回首页，依次进入人生之书和记忆之家。两个内容页都用右上角“退出”回首页。

旁白：

> 人生之书收着我亲口讲过的一生，记忆之家收着我们愿意彼此看见的故事。拾光——先把话说下来，再让记忆慢慢长成书。
