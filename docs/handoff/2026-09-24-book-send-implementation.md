# 书稿发送实现与验收记录

日期：2026-09-24。工作树 `.worktrees/codex/book-send-sharing`，分支 `codex/book-send-sharing`。本地实现完成；未部署、未修改线上开关、未生成二维码。原基线 `8db29e9`；交付前合入 `main@2975f6c` 的独立故事目录修复。

## 用户确认与范围

- 目录顶部“发送”展开“发送给家人 / 发送到社交媒体”。
- 家人沿用每个人/每份邀请的已有阅读、改写、再邀请、复制权限，不统一为只读。
- 社交内容由用户选择：整本书、多章、原文选区。
- 用户授权开始后，按推荐方案实现分页图片和一张正文长图、三档字号；封面始终单独一张。

## 实现

- `book.ts/wxml/wxss`：目录第三按钮为发送；章节既有选段入口保留。等待 `finishEditing()` 成功后导航，重复点击、离页、切章、受保护副本、未保存版本均受保护；没有修改自动保存内部逻辑。
- 邀请页只改布局和逐邀请权限说明，保留原 TS 与后端语义。既有邀请显示自己的权限；没有新增另一套权限来源。
- `bookSend.ts`：本人私有准备快照，固定账号 scope、story/revision/version；保留完整文字、空行及 Unicode。正文照片不自动加入。只读预览前重新核对完整快照；不从编辑缓冲取分享正文。
- 社交页：章节多选、原生只读 editor 直接选择文字；封面晚到只更新图片；离页清除私人内容。生成前、生成后、保存批次前重新检查账号/书稿与服务端授权。账号复核失败清掉旧正文、封面与图片。
- `bookImageLayout.ts`：测量实际字体宽度、保留换行和全部字符，750px 宽分页（1080px 高）或长图（上限 6000px）；超长明确拒绝并提示分页，不截断正文。章节标题与首行尽量同页，最多 160 张正文图；书名过长明确提示。
- `bookImageRenderer.ts`：Canvas 2D 实际排版；沿用已审核现有封面，没有封面时用内置图；AI 文字/封面标注。串行生成文件，尺寸可控，超时、取消、迟到导出回调清理文件。已修复微信 getImageInfo 返回内置图片路径缺开头斜杠造成的加载失败。
- 保存：用户先检查全部图片，再点击保存相册。批次失败保留已成功索引，重试重新核对权限并只存剩余图片。离页停止后续保存；已交给系统的单张保存无法撤回。保存前按批次核权，不声称每张写入前都调用服务端。打开相册权限设置后返回会按隐私策略清空旧预览，可能需重新生成。

## 云端协议与边界

新增 `storyBooks` 两个 action，均需要现有 `accessEnabled && shareCardEnabled && family canary`；capabilities 新增同条件的 `bookExport`。不部署、不改环境变量。

- `bookExportPreview`: `{storyId, revisionId, expectedVersion, scope, chapterIds, excerpt?}`。scope 为 book/chapters/text；text 的 excerpt 是 `{chapterId,start,end}`，offset 为 UTF-16，拒绝拆分代理对。familyId 由服务端身份决定；不信任客户端正文或 openid。
- `bookExportImages`: 同一选择加 `{descriptorId}`。返回 `{descriptor,coverUrl}`，仅封面签名 URL，有效期请求 300 秒；没有私有 fileID。
- descriptor 包括 id、storyId/revisionId/storyVersion、title、chapters[{id,title,text}]、coverImageId、containsAiText。哈希同时绑定实际封面 fileID，替换资产会失效。
- 服务端从当前已保存修订重建完整正文，章节顺序由书稿决定；继承已有 draft 验证（全稿最多 20000 字等），本模块另设选择上限。全书不会静默丢字。
- 只允许所有者；受保护副本拒绝。改写、再邀请或其他阅读授权不会提升成所有者导出权。
- 每个选中章节的文字来源都须允许 view/publish/export；原文摘录也保守检查所在章节的全部文字来源。这可能拒绝同章内部分可导出的文字，后续可细化来源切片，但不能放宽为不核权。
- 复用已验证微信身份，完整所选标题和正文调用既有分块内容审核；审核后重新检查版本、身份、来源权限。
- 封面必须属于当前 family/story、purpose=cover、moderation=pass，未删除且无受保护来源，云文件路径属于当前书；签名后再次核查。没有封面允许内置图，不调用付费生成。
