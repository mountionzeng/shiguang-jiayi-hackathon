# 微信端删除入口可发现性修复

日期：2026-11-04。继续 document07-miniapp-acceptance 候选工作树；未改主仓其他在研内容。

## 问题与改动

用户在微信端找不到删除书籍和记忆的入口。此前记忆列表需侧滑，旧故事详情有删除，但当前书架直接开书；书内更多菜单也已有删除，仅在目录视图且满足 storyId、savedRevisionId、非 protectedCopy 等条件时出现，用户难以发现。

- 人生之书首页新增“管理书籍”，展开带书名的管理列表，每行明确显示“删除”；完成管理可回到书架。
- 记忆卡片显示“删除”，使用 catchtap 防止同时打开记忆；详情顶部显示“删除这段记忆”，保留原有侧滑入口。
- 沿用远端优先软删除和最近删除恢复；删书保留原始记忆及版本，删除记忆不改变已写入书的文字。
- 书籍删除确认期间锁定重复操作，取消和失败后解锁；记忆保存、生成、对话期间阻止删除，详情有未保存内容时明确提示，删除成功关闭对应编辑器。

## 验证

类型检查和完整 1680 项测试通过，日志 /tmp/shiguang-delete-entry-full.log。新增选择指定书籍、取消、重复请求、源记忆保留，以及详情删除后退出和写入期间阻止删除的回归。git diff --check 通过。完整测试后仅调整按钮 CSS 宽度，并在开发工具视觉核对。

微信开发工具实际点击核对：书架管理入口与五本书的删除按钮可见；打开书籍删除确认后取消，书籍保留且按钮解锁。记忆列表显示 17 段，卡片删除按钮能直接打开确认且不会误进详情；取消后打开五张照片的真实记忆详情，顶部“删除这段记忆”可见，再次打开确认并取消，五张原件仍保留。本轮未实际删除用户书籍/记忆；不能把确认取消测试描述成新入口完整删除恢复验收。

本次无云函数改动，无需部署删除服务。仍为开发工具候选，尚未上传手机内部包、提审或正式发布；完整两个故事和新包发布验收仍未完成。
