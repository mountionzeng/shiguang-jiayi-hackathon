## 开工顺序

1. 阅读完整体验主文档、计划和模块交接；核验源码，约定文件归属，先查已有编辑/对话/版本保存成果。
2. 实施同页阅读、聊天、手改与整理预览；同步核实保存及来源合同，区分已保存正文、草稿、整理候选和云端权威版本。
3. 接通更新当前与另存日期版本，两条分支都重新打开核对；不能将本地历史编号当作权威保存成功。
4. 将顶部发送接到准确保存结果上；发送任务负责现有 social/分页/多封面导出，图片任务提供候选与单张生成查询接口。
5. 验收从旧记忆阅读、连续聊天、手改、预览、两种保存到发送图片的整个流程；只完成发送模块不能结束任务。

## 已确定的实现边界

- 打开旧记忆先展示完整正文，不自动转采访；上文档下聊天是用户已选择的布局。
- 整理结果先预览、明确确认后保存；更新当前与另存日期版本是两个可见动作。另存保留原版，同日多次可区分，不丢手改、不覆盖并发更新。
- 发送前有草稿时复用同一文档预览与保存选择，不能默认覆盖当前记忆。
- 正文图由现有文字排版生成，不调用 AI 重新绘字；不得截字、漏段落或缩小到不可读来硬凑张数。
- 已有封面可直接选；生成候选数与最终导出数分别展示。现有单张任务顺序编排即可，首版不新增批量付费 API 或另一套任务状态机。
- 默认本次分享选图不自动改变书封面。保留显式「设为书封面」原功能，两种动作不可混淆。
- 每张生成使用稳定请求标识；未知结果先查原任务，不能盲目重发。取消只停止未提交部分，不承诺已提交任务免费撤回。
- 现有 AI 同意与额度检查继续生效。自动化真实付费测试仅在当前有效授权/额度明确时进行；不把本次“开工”解释成无限测试额度。
- 云端逐张验证封面归属、用途、审核状态、文件与源版本；预览 URL 不是导出许可。
- social 跳封面返回后，仅恢复同账号、同来源且重验通过的选择，不能为了保留选择删除隐私清理。

## 未决项与推进策略

**亲人邀请语义仍未收到明确答复。**已问用户「阅读这段记忆」还是「加入记忆之家邀请海报」。不要把本次开工当作用户选择其中一项。可以先完成菜单、复用现有确定的书稿邀请、继续朋友圈主流程；涉及单记忆接收范围的最终行为待确认，不扩大权限或替换邀请类型，也不要重复追问阻塞其他工作。

**历史修订来源、可生成上限和分页可行范围**需从现有实现和实测确认。先补接口与边界，再确定 UI 可选范围；不要声称现有服务已支持。遇到确实需要另建子系统才能解决的缺口，带最小差异和替代方案回报，不能无限扩大为新平台。
