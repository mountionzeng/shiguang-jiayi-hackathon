## 输出质量问题

整理正文包含近义重复：先写“我坐在靠窗的椅子上，翻一本植物图鉴，翻了半小时”，又写“那半小时里，我坐在靠窗的椅子上翻着那本植物图鉴”。后续书稿继承了这处重复。

原始素材短于目标字数；提示词已有“信息不足宁可短一点”限制，但本次仍出现扩写重复。不能仅凭 HTTP 200 和 JSON 合法就判定文字质量通过。后续宜降低短素材的目标字数压力，并评估该模型推理配置与延迟；本轮没有修改提示词或追加付费测试，也不通过程序盲目删除用户有意重复的原话。

## 真实页面缺陷与修复

在企业小程序开发工具进入“我的 → 小忆记住的事”，显示“暂时无法读取，请稍后重试”。只读调用 `personalMemory` 的 list 动作得到 `functions execute fail`，底层错误格式为：

```text
document.get:fail document with _id <account-id> does not exist
```

身份校验已经通过；失败出现在读取尚未创建的 `personal_memory_controls` 记录。仓储原先只识别 `document does not exist` 等格式，没有识别真实 SDK 在中间插入 `_id` 的形式，因此无法返回默认关闭状态。

修复只增加对该特定“文档不存在”格式的识别，并同步 personalMemory、chatInterview、organizeMemory 的独立部署副本；没有放宽身份、同意、数据权限或模型发布开关。

回归测试先使用真实 SDK 错误格式复现了 4 个失败，修复后全部通过；另验证权限错误、网络错误、集合缺失仍抛出。全量类型检查和 **808 项测试通过**（此前 806 项）。首次只读访问不创建控制记录。
