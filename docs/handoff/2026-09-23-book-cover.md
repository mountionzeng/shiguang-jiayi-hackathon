# 全书封面与首页同步

## 功能与范围

用户要求在书内点击封面，选择本书上传的照片或已生成的图片，结合全书正文生成封面；选用后首页同步。

- 目录现有封面处新增「制作封面 / 更换封面」入口，未保存改动时先提示保存。
- 新页面展示本书可用参考图，最多混选 3 张；也可不选，仅按全书文字生成。
- 每次生成专门说明全书正文及当次所选图片发送至 TokenHub；照片通过 photoAccess 的 ai-reference 权限链读取 small 版本。
- 全部已保存章节按顺序发送，不沿用章节插图的 4000 字裁切。超过 120000 字时明确拒绝，不静默省略后文。
- 参考图经看图模型提炼视觉特征（画风、配色、可见物件），再指导生图；不是保证逐像素保留或人脸身份复刻。
- 竖版 768×1024，延用配图限额、审核、质检、AI 文件标识、任务幂等和恢复机制。云端完成不自动选用。
- 用户点「设为封面」后事务性更新该故事 coverImageId、imageIds 和版本号；不改写章节正文。仅当前书、未删、已通过审核的 cover 类型图可选用。
- 书内和首页都读取同一 coverImageId，切换故事时防止较慢的旧请求覆盖新封面。支持恢复原纸本封面。
- 默认分享仍只分享小程序首页，不附带书稿或私人图文。

## 本地验证

类型检查与 830 项测试通过，包括全书末章纳入上下文、长度超限、明确授权、照片和插图混选、跨书/跨账号/未审核拒绝、并发版本保护、重复请求不重复付费和页面选用反馈。云函数新文件语法检查通过。
