# 拾光家忆故事进入电脑

2026-09-14 按产品方向纠正跨端数据流：微信端“拾光家忆”选择故事并生成一次性电脑登录码，电脑兑换后进入同一微信主体的 Drinking Time 账号继续制作。旧的邮箱关联和“网页故事导入微信”流程已移除。

故事快照包含有效故事的记忆字段与当前书稿章节；最近删除的故事由现有 `storyShelf` 统一过滤。相同内容使用稳定修订摘要，重复生成码不会产生重复故事。新修订作为新快照导入，避免覆盖电脑端已经编辑的内容。

书稿照片现已增加微信云开发备份：原图仍留在手机，只上传显示图和小图两份压缩图，上传可中断并在再次打开小程序或网络恢复后继续。照片默认只有上传者本人可读；受邀家人必须同时拥有引用该照片的记忆阅读权限，且照片的平台检查明确通过。用户可在「我的」查看数量和占用，并两次确认后删除自己的全部云端照片。

这项云端备份尚未改变跨端桥接协议：故事快照仍只带章节里的 `photoId` 引用，不向 Drinking Time 传照片字节或云存储地址。电脑端需要显示照片时，应另行设计一次有时效、可撤回且逐张鉴权的取图协议，不能把微信云存储临时链接当作长期素材地址。
