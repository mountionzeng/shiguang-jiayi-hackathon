# 拾光家忆故事进入电脑

2026-09-14 按产品方向纠正跨端数据流：微信端“拾光家忆”选择故事并生成一次性电脑登录码，电脑兑换后进入同一微信主体的 Drinking Time 账号继续制作。旧的邮箱关联和“网页故事导入微信”流程已移除。

故事快照包含有效故事的记忆字段与当前书稿章节；最近删除的故事由现有 `storyShelf` 统一过滤。相同内容使用稳定修订摘要，重复生成码不会产生重复故事。新修订作为新快照导入，避免覆盖电脑端已经编辑的内容。

当前照片文件仍只保存在手机本机。快照会带上章节中的 `photoId` 引用，但不会把本机照片字节伪装成已传输；后续应建立用户确认、鉴权并可中断的照片上传流程。
