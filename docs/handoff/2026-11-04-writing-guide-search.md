# 材料写作引导、公开资料搜索与写作偏好

用户要求把本次五页材料的一问一答写作过程复现在小程序中，并明确要求跨次记住每位用户的写作偏好，可查看、修改和清除。继续现有验收候选，不改主仓在研内容。

## 实现

- 普通对话明确识别文章作者和用户的身份；用户没有想法时主动给切口或短试样，不重复追问不知道的事实；当前纠正优先。材料全文收起至“查看已读取材料”，首屏仅显示简短说明和一个问题。
- 对话增加“AI查资料”，明确搜索请求也可进入同一入口。用户确认可编辑的公开检索词后，通过既有 TokenHub Chat API 的 web_search_options 使用轻量版搜索；不将照片、原文、对话和个人偏好提交至启用搜索的请求。
- 仅接受服务响应 search_results 的来源链接，拒绝无来源、截断、无对应编号和不安全协议；来源可复制。搜索失败保留输入和检索词、不伪造检索结果、不自动重试付费。结果作为外部资料供当前对话使用，不加入用户亲述 answers；目前结果只保留在当前会话，未实现搜索档案跨会话保存。整理器仍以用户原稿与明确补充为事实依据，不会自动将搜索结果采纳进成稿。
- “写作偏好”入口位于对话和“小忆记住的事”，服务端仅在登录账号 user_accounts.writingPreferences 保存用户明确输入的500字以内设置，不推测或自动覆盖。读改均按服务端身份，写入用 revision 防止旧页面覆盖新设置；清空后停止使用，生成过程中变化时拒绝释放旧偏好结果。个人访谈和整理都会使用偏好，家庭访谈不混入个人偏好。
- “自动进化”的本轮边界：对话立即响应纠正，明确偏好跨次生效，产品反馈落实为代码及回归测试；没有自动训练模型或无人审核自改代码。
- 搜索调用计量不套用纯文字费率，记录搜索次数并标为待核算。四份既有部署计量副本保持相同。
