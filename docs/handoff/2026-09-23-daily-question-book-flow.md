# 每日一问与记忆入文修复

## 用户反馈

回答每日一问后没有继续深入引导；把记忆放入文章时，选定目标后不知道下一步。用户希望问题帮助自己思考，不由 AI 代替用户得出结论。

## 原因与修复

- `interview.send` 在客观记录故事中直接返回，连从每日一问进入的对话也不再追问。现在每日一问入口显式开启引导；客观记录书稿仍按原话整理，不向追问模型读取其已保存正文。普通客观记录入口仍不调用 AI。连续两轮的问题与回答都传给模型，并阻止等待期间重复发送或提前整理。
- 追问提示词原先允许普通回答后只回应不提问。现在默认简短回应加一个贴着前文的问题，从用户愿意谈的细节逐渐深入；明确保留停止、暂停、只记录的例外，不预设心理动机、不替用户回答。提示词断言通过，不等于真实模型质量已验收。
- 书稿页把整理候选限制成目标书已关联的记忆，导致从记忆库带来的新片段被过滤；切换书又会覆盖选中的素材。现在候选使用本人的可用记忆库，正文及章节目标仍限于所选书。切换目的地保留已选记忆，空书也能生成第一章。
- 用户主动点“下一步：预览正文”时才用现有服务将新素材关联到目标故事，并沿用版本校验和服务端来源校验。只是选择故事不写数据；预览不写章节正文，确认后才保存新版本。取消预览保留已关联素材，原始记忆不删除。
- 增加固定底部按钮及已选记忆数，显示切换中、整理中和写入中状态。亲友受保护副本仍拒绝整篇改写。
