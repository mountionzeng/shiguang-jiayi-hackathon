## 2026-09-29 书封加载与外缘修复

- 用户反馈：书封加载慢，外边像矩形，希望保留原纸边材质。
- 根因：封面越界放大后直接铺在透明书框下，原书框透明的外缘露出了矩形封面；书框 `aspectFill` 还会裁掉上下部分。每次冷启动只缓存临时书框，封面查询、下载、配色仍需重复进行。

- 显示图按故事 ID + 当前封面 ID 缓存在本机，限 12 张；在加载当前云端故事列表后才读取对应缓存。换封面、缓存清理或文件丢失会重新生成；缓存写入失败可继续使用临时图，不阻止显示。清理范围仅限本功能产生的文件。
