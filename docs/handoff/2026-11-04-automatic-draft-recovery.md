## 问题与修复

上一轮阻止未同步草稿进入分享，却没有完成自动恢复。articleConflict 为 true 后保存直接返回 false；整本书版本因书名、另一章、新增章节而变化，也被当作当前章冲突。真实云函数错误外层 error 是 STORY_BOOK_ERROR，具体 code 才是 VERSION_CONFLICT，客户端此前取错了字段。旧整书草稿被转存到 retained 后也没有自动补存路径。

- 从不可变历史修订取得本机草稿的基线，将本机实际修改与最新云稿合并。书名、章节名、正文和其他章节的独立修改可以共存，新章节及来源信息保留。
- 当前章、其他章以及旧整书格式的待存稿，在重开、恢复联网、离开编辑和分享前自动补存；网络未知结果重试原请求 ID 和原 payload，明确版本冲突后才重新合并。
- 保存过程中继续输入，自动接续保存；迟到回执不倒退新版本、不删除另一页面的新草稿。书名及旧编辑器输入也进入自动保存。
- 真正同一字段的不同修改保留双方，不盲目覆盖。没有新增专门冲突选择界面，因此不能声称任意多设备冲突都能自动解决。
- 原始草稿先留本机，得到云端确认才显示保存成功；分享继续等待所有待存内容确认。
