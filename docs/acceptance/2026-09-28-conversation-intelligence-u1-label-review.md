# U1 降级提示标签人工听感评审表

日期：2026-09-28。

判据：把标签念给一位不用电脑的长辈听，对方能否大致听懂“小忆现在是什么状态”。Agent 只准备标签和记录栏，不替用户下结论。

| 状态 | 要念出的标签 | 期望听懂的意思 | 用户结论 | 不通过原因或改法 |
|---|---|---|---|---|
| 模型正常 | 小忆认真想过了 | 小忆正常在想，回复是认真生成的 | 待用户判断 |  |
| 模型不可用 | 小忆暂时没连上，先陪你聊 | 小忆现在没连上更聪明的能力，但还能继续陪聊 | 待用户判断 |  |
| 内容检查日限制触发 | 小忆今天有点迟钝，先按常问的陪你说 | 今天临时不太灵，只能按常见问题陪你继续说 | 待用户判断 |  |
