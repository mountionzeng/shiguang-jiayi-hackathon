# 有声故事发布门禁

本功能默认关闭。以下每项都有可复核证据后，才可逐项启用对应环境变量：

1. 腾讯云账号已核实 TTS、VRS、字幕、并发和价格上限；本人授权样本已完成试听。
2. 数据库与存储已应用 `deploy/story-audio` 的私有规则；用不同账号直接读写的负向测试失败。
3. worker 在测试环境实际完成短文、长文、纯文字和图文作品；开头、中段、结尾字幕与画面一致。
4. iOS 与 Android 真机验证录音、暂停、跳句、静态降级、相册保存和账号清空。
5. 灰度只允许已确认账号；观察 unknown、过期租约、队列等待、失败率和供应商用量。

回退只关闭新提交与 worker 领取：保留状态查询和已有作品读取。重复计费、权限泄露或持续崩溃立即停写；不删除任务证据，不把云端失败伪装成本地成功。
