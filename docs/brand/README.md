# 拾光 · 品牌资产

## 标志：双鸟相伴

两只抽象小鸟一大一小、相向依偎，表达老人与家人、两代人之间的陪伴与共同回忆。

- 原创手绘矢量，不临摹任何参考图，不含第三方签名或水印。
- 头部做大、喙并进轮廓、身体收紧，因此在导航与头像级尺寸下仍能辨认出是两只鸟。
- 图形标与中文名称分开：本目录只提供图形标，"拾光"字样在界面里由 WXML 与图形标并排组合，不做成一张合并图片。

| 文件 | 用途 |
| --- | --- |
| `logo-mark.svg` | 双色主版本，透明背景 |
| `logo-mark-mono.svg` | 单色备用版本（深墨绿），用于单色印刷与低对比场景 |
| `logo-mark-on-light.svg` | 浅色背景版本，带宣纸白圆角底 |

## 在小程序里怎么用

标志以 SVG data URI 内联在 `miniprogram/app.wxss` 的 `.brand-mark` / `.brand-mark-mono` 两个类里，
用 `width` 和 `height` 控制尺寸即可：

```html
<view class="brand-mark" style="width:44rpx;height:44rpx"></view>
```

**运行包里不放二进制图片资源**，主包不会因为标志变大。修改 SVG 之后需要重新生成 `app.wxss` 里的 base64。

## 配色

- 玉石绿 `#176b54`：大鸟，也是已确认状态与品牌主色
- 湖水蓝 `#2f6e8f`：小鸟，也是家庭共享区域
- 深墨绿 `#1f3a34`：单色版本
