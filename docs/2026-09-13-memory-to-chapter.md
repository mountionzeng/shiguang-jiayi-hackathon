# 记忆整理进正文

实现入口：记忆列表“选择记忆，整理进书”；记忆详情“整理进书 · 预览后写入”。

流程：选择书 → 勾选记忆 → 选择已有章节或新章 → 生成可编辑预览 → 确认写入。
新章根据素材生成标题，用户可改；少量素材先写一章。已有章节管理继续支持改名、排序、移动记忆及历史恢复。
素材分组与写入正文明确区分。记忆详情显示已写入的位置，可跳到对应章节。

数据约束：预览不持久化；确认前检查素材指纹和版本；原始记忆与历史版本保留；取消不写入。长于 AI 当前输入限制（4000 字）的已有章节要求新开章，避免截断重写。在线 AI 不可用时明确标识原话整理。

验证：类型检查通过；190 项测试通过，新增取消预览、素材变化拦截、预览改稿确认保存，并更新已有整理与照片保留回归。

本次提供开发预览，尚未发布正式版；未实现自动生成多章目录或自动拆分已有章节。
