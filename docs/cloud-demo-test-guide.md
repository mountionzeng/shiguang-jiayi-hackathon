# 云端体验版试用指南

本文档用于测试当前 `dev_backend` 分支的小程序体验版。目标是先把小版本跑稳：文字投稿、云端保存、老人确认、生成第一章，并保留原始来源。

## 云数据库集合

环境 `cloud1-d0g8c8yg0513a6068` 已创建文字 MVP 必需的集合：

- `families`
- `family_members`
- `source_records`
- `memories`
- `biography_drafts`
- `generated_artifacts`

`ensureCloudCollections` 仅供部署维护使用，不由小程序客户端调用。调用前必须在云函数环境变量中临时设置至少 24 位的 `COLLECTION_BOOTSTRAP_TOKEN`，并随事件传入相同的 `bootstrapToken`；完成后应移除环境变量。初始化是幂等的，集合已存在时不会清空或覆盖其中的数据。

后面要接图片、语音、视频和 AI 任务时，再使用：

- `assets`
- `ai_tasks`

## 当前试用权限

当前版本还是体验版演示，为了让多个体验账号能共同看到同一份演示数据，集合需要允许体验成员读写演示数据。

建议只在演示环境中使用宽松权限；正式版本要改成云函数写入和按家庭成员校验权限。

## 怎么判断云端已接管

打开小程序后看页面文字：

- `数据：微信云端`：正在使用微信云数据库。
- `数据：本地兜底`：云端不可用，当前数据只保存在本机。

如果显示本地兜底，优先检查：

- 云开发环境是否是 `cloud1-d0g8c8yg0513a6068`
- 集合是否已创建
- 数据库权限是否允许体验账号读写
- 当前微信号是否在小程序体验成员/开发成员中

## 试用流程

1. 首页点击“重置演示内容”，云端会重新写入虚构家庭数据。
2. 点击“进入林家的拾光房间”。
3. 输入一段文字记忆并提交。
4. 到云数据库查看：
   - `source_records` 应出现原始文字来源。
   - `memories` 应出现可审核的记忆条目。
5. 进入“老人核对”页，确认或标记冲突。
6. 到云数据库查看：
   - `source_records.reviewStatus` 和 `memories.reviewStatus` 应同步变化。
7. 进入章节页，点击生成第一章。
8. 到云数据库查看：
   - `biography_drafts` 应保存当前草稿。
   - `generated_artifacts` 应追加一次生成结果。

## 当前还没做的真实产品能力

- 还没有真实家庭邀请和多家庭切换。
- 还没有按 openid 区分真实投稿者身份。
- 还没有上传图片、语音、视频到云存储。
- AI 生成目前仍默认关闭；接入 API key 后再打开云函数生成。
- 正式隐私权限、删除撤回、内容安全审核还没完成。

当前版本适合小范围体验：验证多人能看到同一份云端演示数据，以及原始文字和 AI 结果分层保存。
